## How to Update This File

1. Add a new section at the top for each release
2. Use the categories: Added, Changed, Deprecated, Removed, Fixed, Security
3. Write clear, concise descriptions
4. Include links to issues/PRs where relevant
5. Update the version number and date

### Version Numbering

- **Major (X)**: Breaking changes, major new features
- **Minor (Y)**: New features, non-breaking changes
- **Patch (Z)**: Bug fixes, minor improvements

### Example

```markdown
## [1.2.0] - 2026-10-15

### Added
- New combat system with combo mechanics (#45)
- Support for multiple save slots (#67)

### Fixed
- Crash when interacting with locked doors (#89)
- Dialogue not progressing after choice selection (#92)
```
