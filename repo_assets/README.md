# Repo Assets — External Code and References

## Overview

This folder contains external code, references, and educational materials collected from GitHub repositories and other sources. These assets are used to enhance and accelerate the development of **Pension Benedito** and the **NarrativeActionKit** framework.

## Folder Structure

```
repo_assets/
├── GAS/                    # Gameplay Ability System
│   ├── Core/              # Core GAS classes
│   ├── Abilities/         # Ability implementations
│   ├── Effects/           # Gameplay effects
│   ├── Attributes/        # Attribute sets
│   └── Documentation/     # GAS documentation and guides
│
├── Combat/                # Combat system references
│   ├── Melee/            # Melee combat examples
│   ├── Ranged/           # Ranged combat examples
│   └── AI/               # Enemy AI for combat
│
├── AI/                    # Artificial Intelligence
│   ├── Behavior Trees/   # BT examples
│   ├── Navigation/       # Navmesh and pathfinding
│   └── Perception/       # AI perception system
│
├── Dialogue/              # Dialogue system references
│   ├── Branching/        # Branching dialogue examples
│   ├── UI/               # Dialogue UI widgets
│   └── Data/             # Dialogue data structures
│
├── UI/                    # User Interface
│   ├── HUD/              # HUD examples
│   ├── Menus/            # Menu systems
│   └── Widgets/          # Custom widgets
│
├── Utilities/             # General utilities
│   ├── Save System/      # Save/load examples
│   ├── Object Pooling/   # Object pooling patterns
│   └── Async Loading/    # Async asset loading
│
└── Examples/              # Complete example projects
    ├── Action RPG/       # Epic's Action RPG sample
    ├── Lyra/             # Lyra reference (if applicable)
    └── Community/        # Community examples
```

## How to Use

### 1. Reference Code
Use the code in this folder as reference for implementing similar systems in our project.

### 2. Copy Patterns
Copy design patterns and adapt them to our specific needs.

### 3. Learn Best Practices
Study how Epic and the community implement GAS and other systems.

### 4. Avoid Direct Copy
Don't copy code directly without understanding it. Adapt and improve.

## Sources

All code in this folder is collected from:
- Epic Games official samples (MIT License)
- Community repositories (check individual licenses)
- Educational tutorials and guides
- Documentation and examples

## Licensing

Each subfolder contains a `LICENSE.md` file explaining the licensing terms of the code within. Always check the license before using any code.

## Contributing

When adding new external code:
1. Create a subfolder with the repository name
2. Include a `README.md` explaining what it is
3. Include a `LICENSE.md` with the original license
4. Document how to use it
5. Update this main README
