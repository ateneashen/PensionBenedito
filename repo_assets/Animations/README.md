# Animations - Quaternius Universal Animation Library 2

## Source

- **Website**: https://quaternius.com/packs/universalanimationlibrary2.html
- **License**: Free for commercial and non-commercial use
- **Format**: FBX

## How to Download

1. Go to: https://quaternius.com/packs/universalanimationlibrary2.html
2. Click "Download" button
3. Extract the ZIP file
4. Import FBX files into UE4.27

## Available Animations

### Movement
- Walk (forward, backward, left, right)
- Run (forward, backward, left, right)
- Sprint
- Idle
- Jump
- Fall
- Land

### Combat
- Attack (light, heavy)
- Block
- Dodge
- Hit reaction
- Death

### Interaction
- Pick up object
- Open door
- Read document
- Push/Pull
- Climb

### Emotes
- Wave
- Point
- Nod
- Shake head
- Sit

## Import Settings for UE4.27

1. **Import as Skeleton**: Use our character skeleton
2. **Import Animations**: Check "Import Animations"
3. **Animation Length**: Use "Exported Time"
4. **Convert Scene**: Check "Convert Scene Unit"

## Retargeting

If animations don't match our skeleton:
1. Create IK Retargeter
2. Map bones from Quaternius skeleton to ours
3. Retarget animations

## Application in Pension Benedito

- **Player**: Walk, run, idle, interact, combat
- **NPCs**: Idle, dialogue gestures, reactions
- **Enemies**: Combat animations, patrol, alert
